# 客户 UAT：部门访问控制

适用：`DEPARTMENT_ACCESS_CONTROL_ENABLED=true`（默认 NBYS 生产）。验收人只需控制台，不查库。

访问入口以实际部署为准（经 Nginx 同域）。运行链接形如 `/chat/{code}`，嵌入形如 `/chatbot/{code}?embed_token=...`。

角色约定：

- 租户管理员：租户 owner / admin
- 部门管理员：`is_department_admin=true`（可为 editor 或 normal）
- 普通成员：本部门成员，非部门管理员

测试数据准备建议：提前建好「技术部」「产品部」两个根部门，技术部下建「前端组」「后端组」两个子部门；各放入至少 1 个应用、1 个知识库、1 个成员。后续用例在此基础上增删。
