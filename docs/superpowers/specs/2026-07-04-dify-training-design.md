**日期**: 2026-07-04
**版本**: 1.1（更新案例 1 和案例 2）

## 1. 培训背景

### 1.1 培训目标
- 让客户能独立使用 Dify 创建应用
- 让客户了解 Dify 的能力边界，知道什么能做、什么不能做
- 让客户能将 Dify 集成到自己的业务系统中

### 1.2 培训对象
- 混合 audience（业务人员 + 技术人员）
- 业务人员：了解功能、能独立创建简单应用
- 技术人员：了解 API 集成、工作流设计

### 1.3 培训形式
- 线下现场培训（面对面）
- 一天（8 小时）
- 讲解 + 实操结合

## 3. 案例设计

### 案例 1：普通智能体 — 法律知识问答助手

**场景**：创建一个能回答基础法律问题的助手

**涉及知识点**：普通智能体、系统提示词设计

**步骤**：
1. 创建普通智能体应用
2. 设置系统提示词：
   ```
   你是一个法律知识问答助手。请遵循以下规则：
   1. 只回答基础法律知识问题
   2. 回答要通俗易懂，避免过于专业的术语
   3. 每次回答后提醒用户"如需具体法律建议，请咨询专业律师"
   4. 不回答涉及具体案件的问题
   ```
3. 测试对话："劳动合同到期不续签，需要赔偿吗？"
4. 测试边界："帮我打官司"（应拒绝）

**预期成果**：能回答基础法律知识，并正确拒绝超出范围的问题

### 案例 2：工作流智能体 — 信息提取助手

**场景**：从文本中提取关键信息（姓名、日期、金额等）

**涉及知识点**：工作流设计器、LLM 节点、变量传递、输出格式化

**步骤**：
1. 创建工作流智能体应用
2. 添加开始节点（输入：待提取的文本）
3. 添加 LLM 节点，设置提示词：
   ```
   请从以下文本中提取关键信息，以 JSON 格式输出：
   - name: 人名
   - date: 日期
   - amount: 金额
   - location: 地点
   - phone: 手机号（如有）
   
   文本：{{input}}
   
   输出格式：{"name": "", "date": "", "amount": "", "location": "", "phone": ""}
   ```
4. 添加结束节点（输出 JSON 结果）
5. 测试文本："张三在 2024 年 1 月 15 日在北京支付了 5000 元，联系电话 13800138000"

**预期成果**：输入文本，输出结构化的 JSON 信息

---

### 案例 3：Chatflow 智能体 — 多轮问答助手

**场景**：创建一个能记住上下文的对话助手

**涉及知识点**：Chatflow、对话流设计、上下文管理

**步骤**：
1. 创建 Chatflow 智能体应用
2. 添加 LLM 节点（带上下文记忆）
3. 设置对话开场白："你好，请问有什么可以帮助你的？"
4. 测试多轮对话："我叫张三" → "你还记得我叫什么吗？"

**预期成果**：助手能记住用户姓名并在后续对话中使用

---

### 案例 4：普通知识库 — 产品手册问答

**场景**：基于产品手册创建知识库

**涉及知识点**：文档上传、分段策略、检索模式

**步骤**：
1. 创建普通知识库
2. 上传一份产品手册（PDF）
3. 设置分段策略（500 字符/段）
4. 测试召回："这个产品有哪些功能？"
5. 查看召回结果，调整分段

**预期成果**：能从知识库中检索到相关段落

---

### 案例 5：工作流知识库 — 智能问答工作流

**场景**：在工作流中使用知识库回答问题

**涉及知识点**：知识库检索节点、检索策略

**步骤**：
1. 创建工作流应用
2. 添加知识库检索节点
3. 关联案例 4 创建的知识库
4. 添加 LLM 节点（基于检索结果回答）
5. 测试问题："产品的价格是多少？"

**预期成果**：工作流能检索知识库并生成回答

---

### 案例 6：API 集成 — 调用 Dify API

**场景**：通过 API 调用 Dify 应用

**涉及知识点**：后端即服务、API 调用、会话管理

**步骤**：
1. 获取 API 密钥（在 Dify 应用设置中生成）
2. 使用 curl 或 Postman 调用 API
3. 发送请求："你好"
4. 查看返回结果

**示例代码**：
```bash
curl -X POST 'https://api.dify.ai/v1/chat-messages' \
--header 'Authorization: Bearer {api_key}' \
--header 'Content-Type: application/json' \
--data-raw '{
    "inputs": {},
    "query": "你好",
    "response_mode": "blocking",
    "user": "user-123"
}'
```

**预期成果**：能通过 API 获取应用回复

### 案例 7：最佳实践 — 会议纪要助手

**场景**：输入会议讨论内容，自动提取关键信息并生成结构化会议纪要

**涉及知识点**：知识库、工作流智能体、普通智能体、提示词工程、API 集成

**步骤**：
1. 创建知识库：上传会议纪要模板（包含：参会人、议题、结论、待办）
2. 创建工作流智能体：
   - 开始节点：输入会议内容
   - LLM 节点 1：提取关键信息（参会人、议题、结论、待办）
   - LLM 节点 2：根据模板生成纪要
   - 结束节点：输出结构化纪要
3. 测试输入："今天开会讨论了 Q3 目标，张三负责销售，李四负责产品，下周三前提交方案"
4. API 集成：获取密钥，调用生成纪要

**预期成果**：输入会议内容，输出结构化纪要，串联知识库 + 工作流 + API
