## 2. 功能点细化拆解

## 3. 原清单表述校正说明

| 原表述 | 建议理解 / 校正 |
| --- | --- |
| 「支持成员转移功能」写在部门管理下 | 拆为：① 成员跨部门调岗；② 应用/知识库「转移部门」。二者不同 |
| 「模型调用权限控制」单独顶在智能体管理下 | 保留为模型白名单；智能体基础管理仍为开源能力 |
| 「发布审核权限控制」 | 现网为「谁能发布到哪些部门」的权限门禁 + 审计，不是独立审批流 |
| 「信息隔离」仅写一句话 | 展开为工作室列表、归属、转移、单资源鉴权 |
| 日志两行空白 | 按 §2.6 补齐：操作审计部分完成；模型调用日志沿用开源 |
