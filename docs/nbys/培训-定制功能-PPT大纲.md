### 第 4 页 · 归属 vs 发布

| 项 | 内容 |
| --- | --- |
| 要点 | 归属 = 工作室/知识库谁能改；发布 = 探索与 `/chat` 谁能用；权责分离。 |
| 简图 | 归属部门 → 工作室可编辑；发布部门 → 探索可用、`/chat` 可打开 |
| 必听 | 全员 |
| 截图 | 无 |
| 讲稿 | 本场最重要概念。用一句话：「改配置看归属，能不能用看发布。」 |

### 第 5 页 · 默认部门与误区

| 项 | 内容 |
| --- | --- |
| 要点 | 默认部门：不可作父部门、不可删、不可移；业务请建独立部门。树：同父唯一名、最多 10 级。误区：「转移 ≠ 取消发布」「发布到 B ≠ B 能改配置」。 |
| 必听 | 全员 |
| 截图 | 无 |
| 讲稿 | 点名两个误区，后面协作页会再踩一次。 |

### 第 6 页 · 部门怎么管

| 项 | 内容 |
| --- | --- |
| 要点 | 入口 `设置 > 部门管理`；仅租户管理员建树；删前检查：无子部门、无成员、无归属资产、无发布勾选。 |
| 必听 | 租户管理员 |
| 截图 | `manual-screenshots/01-department-list.png`、`manual-screenshots/02-create-department.png` |
| 讲稿 | 演示准备：展示部门列表与创建对话框。强调部门管理员页面没有「+ 创建部门」。 |
| 演示 | 开始：建「技术部 → 前端组」（可延续到第 7 页）。 |

### 第 7 页 · 成员与部门管理员

| 项 | 内容 |
| --- | --- |
| 要点 | 创建成员：姓名/邮箱/密码/部门/角色；邮箱全局唯一；部门管理员须「编辑」角色才能建人。任命仅租户管理员；管辖=本部门+子部门。调岗：人走、资产留原部门；曾是部门管理员则徽章取消。 |
| 必听 | 租户管理员、部门管理员 |
| 截图 | `manual-screenshots/03-department-detail.png`、`manual-screenshots/04-create-member.png`、`manual-screenshots/05-move-member.png` |
| 讲稿 | 演示：建编辑账号 → 设部门管理员；口头带过调岗确认框里的「创建的资源」列表。 |
| 演示 | 接第 6 页：任命部门管理员；可选展示移出部门对话框。 |

### 第 8 页 · 工作室 / 知识库归属

| 项 | 内容 |
| --- | --- |
| 要点 | 列表隔离：租户可全量筛选；部门管理员见本部门+子部门；编辑仅本部门；成员无知识库顶栏。新建落入当前账号部门。转移仅租户管理员。知识库「所有部门成员」=精确同部门、不含子部门。 |
| 必听 | 全员 |
| 截图 | 无强制（现场用工作室列表对照即可） |
| 讲稿 | 用一页表讲清「谁看见什么」。演示两部门登录对照工作室列表。 |
| 演示 | 两部门对照工作室列表可见性。 |

### 第 9 页 · 发布与探索规则

| 项 | 内容 |
| --- | --- |
| 要点 | 启用站点 + 勾选发布部门；探索 = 已发布 + 站点开 + 发布到用户部门（或管辖范围）；编辑通常只能发本部门。 |
| 必听 | 全员 |
| 截图 | `manual-screenshots/06-publish-departments.png`、`manual-screenshots/07-explore.png` |
| 讲稿 | 把「探索看不见」拆成检查清单：站点、发布部门、用户所在部门。 |

### 第 10 页 · 标准协作路径

| 项 | 内容 |
| --- | --- |
| 要点 | A 建 → 发布到 B → B 探索用、工作室改不了。仅当 B 要维护配置时才转移归属，并复核原发布勾选。 |
| 必听 | 全员 |
| 截图 | 可复用第 9 页截图 |
| 讲稿 | 演示主线：「研发建、市场用」。强调不要默认转移。 |
| 演示 | 跨部门发布闭环。 |

### 第 11 页 · 运行链接与嵌入

| 项 | 内容 |
| --- | --- |
| 要点 | `/chat/{code}`：须登录；须发布到当前用户部门；所有者也不豁免。嵌入 `/chatbot`：须合法 `embed_token`；复制 snippet 自带；可签发/重置。无 token 提示「嵌入链接无效」。 |
| 必听 | 全员（管理员细讲嵌入） |
| 截图 | `manual-screenshots/08-embed-dialog.png`、`manual-screenshots/10-chat-no-permission.png` |
| 讲稿 | 可选演示：同链接有权/无权；嵌入有/无 token 二选一即可。 |
| 演示 | （可选）`/chat` 或嵌入对照。 |

### 第 12 页 · 模型白名单

| 项 | 内容 |
| --- | --- |
| 要点 | 为何：控成本与合规。谁配：仅租户管理员，入口 `设置 > 成员` → 模型权限。谁查：成员看可用模型（选择器受限）。默认模型始终可用；保存过名单后新模型不会自动加入。 |
| 必听 | 租户管理员为主 |
| 截图 | `manual-screenshots/09-model-permissions.png` |
| 讲稿 | 半页讲清即可；运行时不拦截应用已保存模型这一点口头带过。 |

### 第 15 页 · FAQ

| 项 | 内容 |
| --- | --- |
| 1 | 转移部门后原部门探索仍可见？→ 发布记录未取消。 |

## 演示脚本（穿插，不占独立页）

1. **第 6–7 页**：建部门树 → 创建编辑账号 → 设部门管理员  
2. **第 8 页**：两部门对照工作室列表  
3. **第 10 页**：发布到另一部门 → 探索可见、工作室不可改  
4. **第 11 页（可选）**：`/chat` 或嵌入 token 对照
