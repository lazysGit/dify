## 一、项目概述

### 1.1 建设目标

- 搭建私有化 AI 基础算力与推理底座，支持多模型并存、同时调用，不依赖外部公有 API，保障数据不出域。

- 建设基于开源 Dify 社区版的 AI 应用平台底座，统一承载大模型接入、智能体搭建、知识库管理与用户权限管控。

- 在开源版基础上定制企业级能力：多角色/多部门组织体系、跨部门数据与知识库隔离、智能体全生命周期管理、操作与调用日志审计。

- 建立标准化的项目管理、测试、运维与安全保障体系，确保平台稳定、可管、可控、可追溯。

### 1.2 建设范围与总体架构

项目总体采用分层架构设计，自下而上分为基础设施层、核心能力层、应用层与展示层，并通过部门级 ACL 实现数据隔离与分级授权。

| 分层 | 职责 | 核心组件 |
| --- | --- | --- |
| 展示层 | 用户界面与 API 接口 | Web UI（Next.js）、工作流可视化编辑器、知识库/监控/日志界面、RESTful API、WebSocket 实时通道 |
| 应用层 | 业务逻辑编排与应用管理 | 工作流引擎、RAG 管道、Agent 框架、应用管理、部门权限管理（Dept. Permission） |
| 核心层 | 核心能力提供与领域逻辑 | 模型运行时（Model Runtime）、知识库（向量库）、工具集成、提示词引擎、内容审核 |
| 基础设施层 | 基础服务与资源管理 | PostgreSQL（主库）、Redis（缓存/队列）、向量数据库（Weaviate 等）、对象存储、消息队列 |
| 安全框架 | 数据隔离与分级授权 | 租户 + 部门双层隔离、RBAC 角色权限、操作/调用日志审计（DEPARTMENT_ACCESS_CONTROL_ENABLED） |

从业务价值看，平台将为企业带来“降成本、提效率、促增收、盘活资产、安全合规、快速迭代”六大收益：客户咨询秒级响应、员工资料查询从分钟级降至秒级、市场/合同等文职工作自动化、AI 应用开发周期由数周压缩至 1–2 天、大模型调用成本下降 30%–50%，并通过私有化部署与细粒度权限保障数据安全与合规。
